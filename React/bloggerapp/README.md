# ReactJS-HOL 13: bloggerapp

## Overview
React application `bloggerapp` rendering `BookDetails`, `BlogDetails`, and `CourseDetails` using multiple conditional rendering patterns:
1. Element variables (`if-else`).
2. Ternary operator.
3. Logical `&&` short-circuit evaluation.
4. Switch-case rendering functions.

## Running the Application
```bash
npm install
npm start
```
