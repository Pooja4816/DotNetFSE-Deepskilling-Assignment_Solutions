# ReactJS-HOL 11: eventexamplesapp

## Overview
React event handling application (`eventexamplesapp`) covering:
- Multi-method invocation on Increment click.
- Parameterized event handler ("Say Welcome").
- Synthetic event handling ("I was clicked").
- Form submission event handling in `CurrencyConvertor` (INR to EUR).

## Running the Application
```bash
npm install
npm start
```
