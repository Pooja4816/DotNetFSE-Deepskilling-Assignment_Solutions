\# Exercise 10: Implementing the MVC Pattern



\## Scenario



This exercise demonstrates the implementation of the MVC (Model-View-Controller) Pattern for managing student records. The goal is to separate the application into Model, View, and Controller components.



\## Project Name



`MVCPatternExample`



\## Steps Implemented



\### 1. Create a New Project



Created a C# Console Application named `MVCPatternExample`.



\### 2. Define Model Class



Created a `Student` class with attributes such as Name, Id, and Grade to store student data.



\### 3. Define View Class



Created a `StudentView` class with a `DisplayStudentDetails()` method to display student information.



\### 4. Define Controller Class



Created a `StudentController` class to handle communication between the `Student` model and `StudentView`.



\### 5. Test the MVC Implementation



Created a Student object, updated its details using the `StudentController`, and displayed the initial and updated student details using the `StudentView`.



\## Conclusion



The MVC Pattern was successfully implemented by separating the application into Model, View, and Controller components.
